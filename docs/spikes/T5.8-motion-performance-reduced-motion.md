# T5.8 动画性能与 Reduced Motion 修复报告

日期：2026-08-13

## 结论

本轮审计并整理了 `D:\learn\Tsukiori` 中尚未提交的动画试验。保留了能够观察和验证的优化，同时拒绝同步未接线 token、重复规则和不存在的 Radix 菜单锚点：

- 窄屏工作面板使用 `170ms` 入场和 `130ms` 退场，退场采用加速曲线。
- Dialog Backdrop 的模糊保持静态，只对 `opacity` 执行动画，避免逐帧重绘 `backdrop-filter`。
- 对话区只为真实的欢迎消息、Chat Message、Turn Divider 和 Thinking Block 启用 `content-visibility: auto`，不隔离控件或未知菜单锚点。
- Spinner 使用合成层提示；Reduced Motion 同时把 motion token 归零，并为全部元素、伪元素的硬编码动画设置 `0.01ms` 和单次迭代。
- 没有引入 `--motion-instant`、`--motion-dialog-exit`、`--ease-move` 或 `data-fixed-menu-anchor` 等未被产品行为使用的声明。
