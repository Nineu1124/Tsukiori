# T-LT-D002：保留无法读取的状态文件

实际完成日期：2026-09-21，按本次要求提前执行；原计划日期：2026-09-22。起点：`1d3cce0`。环境：Windows，Node 24.11.1，pnpm 11.9.0。

## 问题与修改

原加载逻辑捕获解析错误后直接建立空状态，构造函数随后保存，导致原文件被覆盖。现在只有文件不存在时才继续查找旧版本；读取失败、JSON 损坏、结构不完整或版本不兼容都会终止初始化。

新增共享读取校验，检查集合、记录 ID、项目与会话关系、团队成员关系。支持的 v1/v2 数据仍按原迁移规则加载；损坏的 v3 不会偷偷降级读取旧文件。桌面启动异常分支为状态错误显示中文提示，错误消息不包含文件正文和底层异常细节。
