日期：2026-08-10

## 结论

通用设置不再保留“可以选择但实际上没有行为”的入口。最小化启动、默认 Runtime / Provider / Model 已连接到真实窗口和 Session 创建路径；不受当前版本支持的英文界面与系统主题明确锁定，高风险操作确认由安全策略强制启用。

## 可观察交付

- BrowserWindow 始终先以 `show: false` 创建，Renderer ready 后才根据本机设置显示或最小化，避免先显示再读取设置；
- 正常产品进程使用 Electron 单实例锁，第二次启动退出并恢复、显示和聚焦现有窗口；Smoke 与隔离截图任务使用独立生命周期，不争用用户实例；
- Preload 只增加只读 `windowState()` 诊断面，返回 exists / visible / minimized / maximized，不暴露窗口控制或 Electron 对象；
- 设置页增加默认 Model，Provider 变化会同步刷新模型列表，保存后新 Session 采用该模型；模型不属于当前 Provider 时安全回退到 Provider 首个已配置模型；
- `language=zh-CN`、`theme=light` 和 `confirmHighRisk=true` 在加载旧状态和更新设置时都会收口，Renderer 不再提交可伪造的未支持值；
- 通用与外观设计截图已重新生成，默认 Model、真实启动说明和锁定能力均在 1600×1000 画面内可见。
