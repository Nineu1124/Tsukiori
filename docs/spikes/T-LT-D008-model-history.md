# T-LT-D008：模型历史独立保存

实际完成：2026-09-28。Windows；Node 24.11.1；pnpm 11.9.0。

Direct API 改为读取独立的完整消息集合，不再从 500 条 UI 事件中拼接上下文。取消隐式的最后 100 条消息限制，发送前克隆消息，避免客户端修改存档。启动和 Checkpoint 回退重建消息集合；UI 会话及全局事件仍分别保留 500、1,000 条。

验证：`pnpm run build` 21/21；`node --test tests/interactive/*.test.mjs` 101/101。新增用例在关闭落盘后插入 1,100 条 Delta，确认第二轮保留首轮完整用户与助手消息；验证超过 100 条的解析，以及客户端修改输入不会污染历史。提交前执行 `npm run check`、`git diff --check`。

本项仍受旧 Transcript 文件容量限制；上下文预算和分段保存由 D009、D010 接续处理。没有把无限消息存储等同于模型无限上下文。
