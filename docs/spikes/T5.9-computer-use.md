# T5.9 Windows Computer Use 实施报告

验证日期：2026-08-03  
平台：Windows x64  
版本：1.0.0-rc.4（候选）

本轮把 cc-haha 中最容易被误用的 Computer Use 能力拆成独立的 Windows 本机桥接：PowerShell 单次 Helper、当前用户前台进程指纹、短时会话锁、前台变化拒绝、逐次动作审批、截图内存回传和退出清理。它不是 OS 安全沙箱，也没有把桌面动作自动暴露给 Runtime；Runtime 只能通过现有权限中心请求，用户仍必须在工作面板逐项确认。

## T5.9-C1 Native Helper

- [x] `apps/desktop/electron-main/windows/computer-use-helper.ps1` 通过 `user32.dll`、`SendInput` 和 `System.Drawing` 编译，并返回 capability JSON。
- [x] Helper 使用单次 stdin JSONL 请求，禁止命令行拼接，输出只包含有界结果或错误码。
- [x] Helper 通过 `GetForegroundWindow`、PID、可执行文件路径、进程启动时间和虚拟屏幕边界提供身份探测。

证据：`node --test tests/computer-use/native-helper.test.mjs`；该测试实际启动 Windows PowerShell，未执行点击、输入或截图动作。

## T5.9-C2 Session Lock 与前台白名单

- [x] 锁定绑定 `ownerId + sessionId`，有效期 5 分钟，锁定者不匹配会拒绝。
- [x] 锁定动作提供 2 秒窗口供用户切换到目标应用；Shell、终端宿主和 Tsukiori 自身不能成为目标。
- [x] 每次动作前重新读取前台进程，PID、启动时间或路径变化即拒绝，避免 PID 复用和误操作。

证据：`tests/computer-use/computer-use-manager.test.mjs` 的 lock、foreign owner、foreground change 和 expiry 用例。

## T5.9-C3 Screenshot 与敏感数据边界

- [x] 截图只写入本机用户数据目录的临时文件，读取为受限 PNG Data URL 后立即删除文件和目录。
- [x] 单张截图上限 8 MiB；宽高和响应均经过有限整数校验。
- [x] Renderer 只收到应用名、PID、启动时间和标题哈希，不收到完整可执行文件路径或窗口标题。

证据：`tests/computer-use/computer-use-manager.test.mjs` 的 screenshot cleanup、bounded response 和 path projection 用例。测试使用 1×1 脱敏 PNG Fixture，不包含用户屏幕内容。

## T5.9-C4 Mouse、Keyboard 与 Approval

- [x] 鼠标坐标必须落在当前虚拟屏幕范围内；点击次数限制为 1–2，按键仅允许左/右/中键。
- [x] 键盘文本上限 4,096 字符，使用 Unicode `SendInput`，不经过剪贴板；快捷键最多 4 个并使用白名单虚拟键码。
- [x] 请求和执行分离：`requestAction` 产生 30 秒单次审批，审批消费后不能重放。

证据：`tests/computer-use/computer-use-manager.test.mjs` 的 invalid input、one-time approval 和 fake Helper action 用例。

## T5.9-C5 IPC 与 UI

- [x] Preload 仅暴露 `computerUseStatus/Foreground/Acquire/Release/Request/Approve` 六个固定方法。
- [x] 工作面板增加 Computer Use 页面，显示 Support Level、锁定目标、截图、鼠标、键盘和快捷键入口；所有危险动作都弹出单次确认。
- [x] UI 明确显示“不是 OS 安全沙箱”，并支持释放锁定与 reduced-motion 视觉规则。

证据：`npm run test:ui`；Computer Use UI 用例与现有无 Node/HTML 注入边界一起通过。

## T5.9-C6 回归与边界

- [x] TypeScript 全量构建通过。
- [x] Computer Use 专项测试 4/4 通过；Windows Helper capability/foreground 探测真实运行。
- [x] 未把截图、动作、窗口标题、用户源码或 Provider 凭据写入 SQLite、Transcript、日志、Fixture 或诊断包。

## 当前仍未宣称的能力

- Runtime 自动调用 Computer Use MCP 工具、远程 H5 控制、IM 集成和桌面宠物仍未接入；这些能力继续保持未实现/unknown，不计入 Local V1 完成率。
- `interceptable` 只表示 Tsukiori 在 IPC 层做了会话锁和逐次审批，不表示 Windows 或目标应用已被 OS Sandbox 隔离。
