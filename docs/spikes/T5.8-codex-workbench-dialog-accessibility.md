# T5.8 Codex 式工作台交互与弹窗可达性补充报告

验证日期：2026-08-10  
平台：Windows x64  
版本：1.0.0-rc.4 开发分支

## 问题与根因

用户截图中的 Agent Team 弹窗虽然显示了右上角关闭和底部取消按钮，但设置弹窗还存在更底层的布局问题：`.settings-shell` 只声明了列轨道，隐式行轨道会被内容最小尺寸撑高，导致主区域比 Dialog 可见边界多出约 30 px。底部保存按钮因此被 `dialog { overflow: hidden }` 裁剪，程序化 `click()` 能成功，但真实鼠标中心点命中的是裁剪层而不是按钮。

本轮把所有模态窗口统一到 `dismissDialog`，并显式限制 Settings Grid 行为 `minmax(0,1fr)`。长表单 Footer 保持在可见滚动区域，关闭、取消、Esc、点击 Backdrop 都恢复焦点到调用按钮。

## 安全边界

- Side Chat 不额外持久化 Prompt；沿用 Session Transcript 本地策略和 Provider 数据出口。
- Renderer 仍不获得 Node、文件系统或进程执行能力；新增接口仅是 `pinProject(projectId, boolean)`。
- 终端高度和 Project Pin 不包含凭据、用户源码、原始 Runtime 事件或完整 Prompt。
