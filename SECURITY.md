# Security Policy

Tsukiori is in an early architecture and protocol-Spike phase and has no stable release.

Please do not open a public issue containing API keys, authentication files, private source code, full prompts, raw Runtime events, cookies, or private logs. Contact the repository owner privately before sharing security-sensitive reproduction material.

The project stores files and application data locally, but selected Agent Runtimes may send prompts, code context, and tool results directly to model Providers chosen by the user.
